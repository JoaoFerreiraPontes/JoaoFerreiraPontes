# João Abrantes

Energy Engineer in training and Developer focused on AI and Embedded Systems. Currently, I apply technology to optimize the wind energy sector.

### Projects I've participated in or am currently working on

* **Data Analyst & Full Stack Developer L1 @ Vestas**: Developing full stack applications and data tools with Python, JavaScript, and HTML/CSS to support the Blades department. I analyze and consolidate operational data for reporting and decision-making. Additionally, I automate team workflows using tools like Power Automate, Smartsheet, and Microsoft Lists.


* **Stack:** Python (Django, Flask, FASTApi, pandas, Polars), Selenium, JavaScript, React, Node.js, MapGL, PostgreSQL.




* **AI Trainer, RLHF & Data Specialist (Alignerr / Outlier / RWS)**: Contributing as an independent contractor and specialist across multiple projects related to AI training, development, and optimization (Fine-Tuning). My work involves Reinforcement Learning from Human Feedback (RLHF) to review code and reduce hallucinations in transformer models, prompt engineering, and complex web scraping tasks mapping HTML, CSS, and Dev Console routes via JSON data labeling.


* **Stack:** Python, Machine Learning, RLHF, Prompt Engineering, RAG pipelines (LangChain, LlamaIndex, Qdrant).




* **Air Quality Sensor Monitor (IoT)**: Developed an embedded system using an ESP32-WROOM (with the ESP-IDF SDK) and a ZPHS01B modular sensor to detect gas and particle concentrations in the air. The system features an interactive configuration menu and transmits real-time air quality telemetry via serial terminal and Bluetooth SPP connectivity.
* **Stack:** C/C++, ESP-IDF SDK, Embedded Systems, UART, Bluetooth.


* [Click here to check out the repository](https://github.com/JoaoFerreiraPontes/Sensor_QdA_ZPHS01B_Projeto)


* **Psychrometric Chart Plotter**: Created an advanced Python script targeted at the HVAC (Heating, Ventilation, and Air Conditioning) engineering field. It generates a standard ASHRAE psychrometric chart and overlays experimental temperature and relative humidity data captured from the input and output of climate control systems.
* **Stack:** Python, Matplotlib, NumPy, PsychroLib.
* [Click here to check out the repository](https://github.com/JoaoFerreiraPontes/Psychrometric-chart-plot-code.git)


* **IoT Temperature Monitor (Raspberry Pi Pico W)**: Engineered a smart monitoring device that turns a Raspberry Pi Pico W into a local TCP server. It receives real-time temperature data from other network devices, displays it locally on an SSD1306 OLED screen, triggers visual and auditory alarms for defined temperature limits, and exports telemetry history to the cloud using the ThingSpeak IoT platform.
* **Stack:** C/C++, Raspberry Pi Pico C/C++ SDK, IoT (ThingSpeak), I2C, Wi-Fi Networks, Embedded Systems.
